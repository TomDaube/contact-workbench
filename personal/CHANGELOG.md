# Personal Contact Workbench: change log

The Personal edition is a clean copy for friends and family: Apple and Android (Google) address books only. It has its own version numbers, separate from the Work edition. It is built from the Work file by build-personal.py, which removes everything work related, and personal-check.js sweeps every screen and help topic for leftovers.

## Version 1.11 (Nov 16, 2026)
- Compare lists can show three circles: pick a Third list to see who is in all three, any two, or just one.

## Version 1.10 (Nov 16, 2026)
- New Compare button next to Format on Contacts: a Venn diagram of two lists (such as Apple and Google). Tap a number to see those people.

## Version 1.9 (Nov 15, 2026)
- New Select all button: tap Select above the list, then Select all to tick everyone shown. Then Delete, Archive or Merge them in one go.

## Version 1.8 (Nov 15, 2026)
- The A–Z letters on the right no longer sit on top of the Windows scroll bar, so they're fully on screen on Windows laptops.

## Version 1.7 (Nov 15, 2026)
- Format filter: new Only in one (e.g. Only in Exchange) and In one, not the other (e.g. Exchange, not in Zoho) sections, alongside In both.

## Version 1.6 (Nov 15, 2026)
- New Dark charcoal color in Settings › Appearance › Color (#2b2d31; a softer gray in dark mode).

## Version 1.5 (Nov 15, 2026)
- Removed the Start over button (Remove all…) from Settings and from Step 1, so everything can't be wiped by mistake.

## Version 1.4 (Nov 15, 2026)
- Buttons are a little shorter and no longer bold (Reset, Search, Choose files and the rest).
- New Button size slider in Settings › Appearance (Clean style), 75% to 125%, default 90%.

## Version 1.3 (Nov 15, 2026)
- Calmer, more consistent buttons in the Clean style: blue for the main action, red text for anything that deletes or removes, soft gray for everything else, one set of sizes. Classic keeps the colored buttons.

## Version 1.2 (Nov 15, 2026)
- New Clean style, on by default: more white space, hairline borders, quiet buttons, one accent color, in light and dark. Settings › Appearance › Style switches between Clean and Classic.

## Version 1.1 (Nov 14, 2026)
- Private saving: each person who opens the app saves their contacts in their own private space in their Claude account (not the shared file store). Nobody else can see them, not even the person who shared the app.
- If the app can't save there (for example it was shared to view only), the cloud badge says Saved on this device only and contacts stay in that browser.
- Help › Where your contacts are kept explains this.

## Version 1.0 (Nov 14, 2026)
- First version, made from Work edition v155.
- Removed: Zoho (including the connector code), NetSuite and sales, customers and leads, work contacts and their settings, Exchange and Outlook wording, and every business detail (company name, NetSuite link, jeweler wording in the AI tidy-up).
- Kept: import of Apple .vcf and Google CSV files, duplicates and merging, clean-up checks, notes and address tidying, groups and tags, archive, photos, and Apple and Google exports.
